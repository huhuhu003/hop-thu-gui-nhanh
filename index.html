Chưa có Client ID

App cần Client ID của Google để ghi vào Drive. Làm một lần duy nhất:

  1. Vào console.cloud.google.com, tạo một project mới.
  2. Bật Google Drive API (APIs & Services → Library).
  3. Credentials → Create Credentials → OAuth client ID → loại Web application.
  4. Thêm Authorized JavaScript origins là địa chỉ nơi đặt file này (ví dụ https://huhuhu003.github.io).
  5. Copy Client ID, dán vào mục Cài đặt bên dưới rồi lưu.

Khi đăng nhập, Google sẽ cảnh báo "ứng dụng chưa được xác minh" — đây là app cá nhân của mình, cứ bấm Tiếp tục là được.
